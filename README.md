# Dalil-Misr-Alraqamia

https://abdulbasetrs.github.io/Dalil-Misr-Alraqamia/ (live demo)

## File Structure

```text
Dalil-Misr-Alraqamia/
├── index.html                              ← الصفحة الرئيسية
├── assets/
│   ├── style.css                           ← كل التصميم المشترك (الهوم + الشرائح)
│   ├── theme.js                            ← زر الوضع الليلي/النهاري
│   ├── presentation.js                     ← منطق الشرائح (كيبورد + Scroll Snap + المؤشر الجانبي)
│   ├── ministries-data.js                  ← بيانات الوزارات والخدمات (اللينكات)
│   └── home.js                             ← بيبني قائمة الوزارات في الصفحة الرئيسية
└── ministries/
    └── housing/                            ← فولدر وزارة الإسكان
        └── alt-housing-attachments.html    ← صفحة الخدمة نفسها
```
